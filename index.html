Make it feel right for your child

Nothing plays automatically. Reading aloud uses your device's speech service and may need a downloaded voice or an internet connection.

A shared routine, not a lock

One correct answer finishes the round, including an answer worked out together. Hints, retries, breaks and switching questions are unlimited. The game never takes away a finished ticket on its own.

The ticket is a visual cue for a grown-up. This game cannot block a TV, control another app, or verify parental permission. "Grown-up corner" is not password protected.

Children's preferences differ. Try it together when things are calm, offer a choice, and stop if it feels stressful. You can use the "All done!" message instead of linking the game to TV. This is a learning game, not a treatment or assessment.

Keep Mochi close

Install from the hosted website, not a downloaded HTML file or a Google Drive preview. Installation is optional; the game also works in a browser tab.

On a Pixel Tablet, open this website in Chrome. Tap the three-dot menu, then Add to Home screen, then Install if offered. Menu wording may vary. If only a shortcut is offered, you can still play in Chrome.

Offline setup has not been checked. Keep an internet connection for the first visit.

Updates never reload your puzzle automatically.

  1. Pixel Tablet: visit the HTTPS website in Chrome while online. Use the menu instructions above or the Install button when available. Open the new Cosy Cat Club icon from the Home screen or app drawer.
  2. Windows: visit the same website in Chrome or Edge. Use the browser's install icon or app-install menu when offered. A normal browser tab works too.
  3. Before going offline: wait until the offline message confirms a complete saved copy. Try reopening the game once with Wi-Fi off. A shortcut or an installed icon alone does not prove offline readiness. Your browser can remove saved website data, especially after clearing storage; if that happens, visit online again.
  4. Updates: check here when convenient. When an update is ready, finish your round, close every tab and installed window of this game, then reopen it. A new visit starts a fresh round. There is no need to interrupt a question.

No accounts, ads, external images, analytics or question uploads. Preferences stay in this browser and do not sync between devices. Reloading starts a fresh round. Reading aloud is optional and handled by your device's speech service. The website host may keep ordinary access logs.

For hosting or backups, keep index.html, pwa.js, sw.js, manifest.webmanifest and the icons folder together. Google Drive can store these files but is not website hosting. Installation and offline setup require HTTPS or localhost, not file://.
